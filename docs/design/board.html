Build specification

Desktop 1280
Frame: 1280px. Operations Console top bar: 68px. Main side gutter: 38px. Publishing and department-owned source actions stay above the fold.

Tablet 768
Navigation condenses to a top bar. Main side gutter: 24px. Metrics remain three columns only when labels fit, otherwise stack. Editor fields become two rows.

Phone 390
Navigation moves into a menu. Main side gutter: 16px. Metrics and forms stack in reading order. Motion is limited to a 180ms state transition and turns off for reduced motion.
