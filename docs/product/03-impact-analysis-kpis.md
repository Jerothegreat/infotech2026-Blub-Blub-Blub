# Impact Analysis & KPIs

**Expected impact:** fewer missed deadlines and walk-in questions for students and offices, with every answer traceable to an official document. Baselines are not in the sources, so each KPI below is measured at pilot start; the targets are proposed and should be presented as goals, not results.

| KPI | Why it matters | Proposed target | How measured |
| --- | --- | --- | --- |
| Grounded-answer rate | Core promise to judges and students | 100% of answers carry a citation to a provided source | Automated check on every response; test set run before demo |
| Refusal accuracy | Proves the bot does not guess | 95%+ of out-of-scope test questions refused | 20-question test set with in-scope and out-of-scope items |
| Retrieval accuracy | Right chunk found | 90%+ of in-scope test questions cite the correct section | Same test set, manual check of citations |
| Missed announcements | Student-side outcome | 50% fewer students reporting a missed deadline | Pilot survey at start and after one term |
| Repeat questions to offices | Admin-side outcome | 30% fewer repeat inquiries on covered topics (scholarships, admission requirements, office locations) | Office tally sheet plus top-question analytics |
| Admin setup time | Adoption | Under 5 minutes to publish a monthly banner; under 2 minutes to add a source file | Timed in the live demo |
| Source coverage gaps closed | Continuous improvement | Share of refused questions resolved by new uploads each month | Gap list in admin analytics |

**Scalability of impact:** each new college is a tenant tag plus its documents. The scholarships and offices files already serve the whole university, while college requirement files (like the CCIS one) are added per college.
